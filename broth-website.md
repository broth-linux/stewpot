# Broth Linux
A **source based**, **musl/busybox** - **POSIX complient** operating system with a custom 
package manager `stewpot`.

---

## About
Built out of spite from the difficulties of using *SMGL* in the modern era and from the love of *KISS linux*,
Broth aims to do what sourcemage couldn't. No bash scripts, no glibc, no broken dependency resolution or any
extra/unnessecary lines of code making the whole toolchain destroy itself nearly every time you try and bootstrap it.
With a dedicated `chef` menu built to be a clone of `sorcery`, as well as having access to command line tools still
gives the promise of simplicity *--* yet still give the user complete control of the system with plain/easy to read `sh` scripts.

---

### Core Features
* Musl libc based
* Busybox userland
* Zero systemd bloat
* Custom POSIX shell package management

---

1. Step one: curl ./enterbroth.sh
2. Step two: run ./enterbroth.sh /mnt/broth-root
3. Step three: Cook recipe source configs.
